# 会议纪要智能分析工作台（可用版）

在保留你原始布局与 UI 的基础上，把展示型原型升级为真实可用的本地网页应用：导入会议文稿即可一键生成结构化纪要，全部数据只保存在本机浏览器。

## 打开方式

双击 `index.html`（推荐 Chrome / Edge）。原始原型文件未改动，仍保留在 `02-原型预览/workbench-preview.html`。

## 已接通的真实功能

- **一键导入**：`txt / md / srt / vtt / docx` 文稿（点击选择、拖拽或顶栏「新建分析」）；音视频需在「设置」中配置 OpenAI 兼容转写接口后自动转写
- **结构化分析**：一句话摘要（关键词高亮）、关键决策、行动项（自动识别负责人与截止时间）、风险与遗漏提醒
- **可视化**：发言人发言占比、议题关注度、关键词云、话题热度趋势（沿用原版黑白图表样式）、重点语句摘录
- **话题时间线**：按主题自动分段；SRT/VTT 自动提取时间码
- **智能问答**：针对本次会议内容提问，返回相关原句与说话人
- **SOP 与建议**：按会议模板生成标准作业流程与工作建议
- **行动项追踪**：跨会议汇总待办、勾选完成、逾期标红、支持手动添加
- **团队协作**：按会议评论（本机保存）、一键复制分享文案
- **模板管理**：例会 / 决策会 / 客户会 / 复盘会，支持新增与切换
- **导出**：复制纪要、导出 TXT、导出真实 DOCX、打印 / PDF
- **设置**：称呼、动效开关、转写接口、术语表、数据导出 / 导入 / 清空
- **工作台总览**：KPI、最近会议、部门概览、发言占比均为真实数据；顶栏搜索可直达记录库筛选

## 技术栈与成熟库（均本地化，离线可用）

- 分析引擎：自研纯函数规则引擎 `js/engine.js`（可离线，支持 Node 单测）
- [mammoth.js](https://github.com/mwilliamson/mammoth.js) 1.9.0：docx 文稿解析
- [docx](https://github.com/dolanmiu/docx) 9.7.1：生成真实 .docx
- GSAP + ScrollTrigger：沿用原版的页面切换与微动效
